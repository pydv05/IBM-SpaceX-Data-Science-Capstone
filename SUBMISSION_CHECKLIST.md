# Submission checklist

1. Create a **public** GitHub repository.
2. Upload this entire repository structure.
3. Open each notebook once on GitHub and confirm it renders.
4. If time permits, run the notebooks locally and commit the executed versions.
5. Run `dashboard/spacex_dash_app.py` and confirm the dashboard starts.
6. Copy the GitHub repository URL.
7. Replace the GitHub placeholder in the final presentation/PDF with that URL.
8. Submit the final PDF to Coursera.
